# REST Countries Explorer 🌍

A responsive country explorer web application built with HTML, CSS, and JavaScript. Browse countries around the world, explore their details, and navigate between neighboring countries.

## 🚀 Features

- **Browse Countries:** Display country cards with flags, population, region, and capital.
- **Country Details:** View detailed information about each selected country.
- **Border Countries:** Explore neighboring countries through clickable border country buttons.
- **Dynamic Navigation:** Navigate between the home page and country details without reloading the page.
- **Number Formatting:** Display population figures with properly formatted thousands separators.
- **Responsive Design:** Adapt the layout to different screen sizes.
- **Interactive UI:** Dynamically generate country cards and details using JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Fetch API
- JSON
